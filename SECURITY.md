# Security policy

## Reporting a vulnerability

Do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting for the repository if enabled. If it is unavailable, contact the maintainer through the email listed on the GitHub profile. Include affected version, impact, and a minimal reproduction. Please allow reasonable time for a fix before public disclosure.

DNS Sentinel is a read-only auditor and currently makes DNS queries through the system resolver. It does not provide a guarantee that a domain is safe, correctly configured, or cryptographically validated. Do not send secrets or personal data in audit output or issue reports.

## Supported versions

Only the latest release is supported during this alpha stage.
