# Contributor Covenant Code of Conduct

We are committed to a respectful, welcoming community. Participants should be considerate, assume good faith, give constructive feedback, and focus criticism on ideas and code. Harassment, discrimination, intimidation, personal attacks, and unwanted sexual attention are not acceptable.

Maintainers may edit or remove contributions that violate this code and may restrict participation when necessary. Report incidents privately to the repository maintainers. Please include enough detail to investigate; reports will be handled as confidentially as practical.

This project adapts the Contributor Covenant, version 2.1. See https://www.contributor-covenant.org/version/2/1/code_of_conduct/ for the full text and attribution.
